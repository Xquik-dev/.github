# Support

Use the affected repository's issue tracker for public SDK, docs, skill, plugin, package, and example problems.

Include:

- Repository or package name
- Version, language, and install command
- Minimal reproduction or request and response shape
- Links to public docs or registry pages involved

Do not include API keys, credentials, cookies, private account data, webhook signing values, screenshots with private data, or private routing details.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md).

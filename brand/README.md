# Xquik Brand Images

- `avatar.png` is the organization picture, 500x500.
- `social-preview.png` is the default repository social preview, 1280x640.
- `social/<repository>.png` holds the custom previews of integration repositories.

The X mark and the wordmark use Dancing Script at weight 700.
Their colors are maroon `#4c2626` and cream `#f5f3f0`.
